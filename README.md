# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：批量合并、风险排序和审批入口
- 续作接管：运行/审批包/基线/忽略规则的续作接管单，仲裁两窗口并发、失效重算与批次恢复
- 历史基线：版本、批准人、原因、关联运行、启用状态和批准当时快照（基准版本、截图摘要、逐区结论）
- 忽略规则：动态区域选择器、作用范围、最大色差和启用控制
- 结果导出：导出包含运行、差异和审批证据的 CSV

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键。

## 续作接管机制

审批包回传时不再直接覆盖基线，而是生成一张「接管单」串起运行、审批包、基线和忽略规则：

- **接管单记录**：基准版本、截图摘要（区域数/像素/差异率/规则指纹的稳定摘要）和逐区结论。
- **并发仲裁**：同一目标（项目/页面/设备/主题）两窗口同时提交时，先到者 `active` 启用并生成唯一基线，后到者留草稿 `draft-conflict` 并列冲突，不重复生成基线；人工确认后到草稿会将先到者置为 `superseded`，旧基线快照仍可追溯。
- **失效重算**：规则或截图摘要一变，未确认接管单（草稿/冲突/已补核）置为 `stale` 重算；已批准（`active`）基线永久保留批准当时快照，不随后续变化改写。
- **旧包待核**：缺少截图摘要的旧审批包进入 `pending-verification`，不自动启用；补传摘要核为一致后为 `verified`，人工确认才接管。
- **批次恢复**：完整接管批次先落库，启用阶段写入失败可从批次重放恢复；重放按 `packageId` 判重，幂等且不重复生成基线。

接管逻辑在 `src/utils/takeover.ts`，可运行纯逻辑验证：

```bash
npx tsx --tsconfig scripts/tsconfig.json scripts/takeover.logic.ts
```
